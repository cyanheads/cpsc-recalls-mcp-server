# 0.2.3 — 2026-10-25

## Changed

- **Recall links and product images** use framework `markdownLink` and `markdownImage`: HTTP(S) destinations retain their URL values, captions render literally, and other schemes remain visible as text.
- **Framework responses** escape tool errors, recovery hints, and query echoes in Markdown; handlers returning after cancellation settle as `RequestCancelled` (`-32011`). Invalid framework configuration fails at startup with the variable name instead of during utility imports.
- **Development tooling** syncs framework skills and advisory attribution, excludes development files from MCPB bundles, and measures text-pass thread CPU time. Hosted connection examples cover Claude Code, Cline, Cursor, and Claude Desktop.

## Fixed

- **Search and recent page budgets** reserve the bytes added by framework enrichment escaping within the 64,000-byte response limit.
