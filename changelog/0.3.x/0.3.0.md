# 0.3.0 — 2026-10-28

## Added

- **`cpsc-recalls-guide` skill** served over MCP as the resource `skill://cpsc-recalls-guide/SKILL.md` (template `skill://{+path}`) via `createApp({ skills: 'skills' })`, and shipped in the npm package, the Docker image, and the `.mcpb`. It covers search-formulation gates, recall-number and identifier quirks, jurisdiction edges, and recall-checking workflows.
- **Agent Plugins** root `plugin.json` and `mcp.json` (mcp-ts-core 0.13.18 template).

## Changed

- **`cpsc_search_recalls` `content[]`**: the `Query:` echo line renders as a code span instead of Markdown-escaped text, e.g. `` Query: `product_name="stroller" AND date_start=2025-01-01 AND date_end=2025-12-31` `` (mcp-ts-core 0.13.18). `structuredContent` is unchanged.
- **64,000-byte page budget** reserves room for the code-span echo and per-line notice quoting, so a cut page stays within budget for any echoed value.
- **README Getting started** is reorganized: hosted `claude mcp add`, local npx, one JSON config, with install and prerequisites under Running the server.
- **`.mcpb` bundle** leaves out repo-local files (root-anchored `.mcpbignore` from the 0.13.18 template) and the framework's build-only files (0.13.18 cleaner). It keeps the MCP SDK's skills runtime modules, which the 0.13.18 cleaner would otherwise strip (cyanheads/mcp-ts-core#794).

## Fixed

- **HTTP transport** no longer retains about 71 KiB per request, so sustained traffic no longer grows the heap. 0.2.3 shipped on mcp-ts-core 0.13.16, which leaked it through the shutdown signal; fixed in mcp-ts-core 0.13.17 (cyanheads/mcp-ts-core#786).
