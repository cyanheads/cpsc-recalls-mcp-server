# 0.3.1 — 2026-10-29

## Added

- **`cpsc_search_recalls` rows** carry `last_updated` and `distributors`, the same values `cpsc_get_recall` returns, and `content[]` renders them as `**Last updated:**` and `**Distributor:**` lines (#25).

## Changed

- **`limit`** on `cpsc_search_recalls` and `cpsc_get_recent` accepts 1–10,000 (was 1–200 and 1–100). A page holds at most 200 and 100 recalls, so a larger `limit` returns a full page with a notice naming the offset to continue from (#24).
- **Advertised text** no longer says CPSC excludes drugs, tires, vehicles, or firearms outright: the jurisdiction note names child-resistant packaging, ATVs and snowmobiles, bicycle tires, and gun safes and locks as CPSC's. Recall numbers are described as five digits with a letter `a`–`d` on some 1998–2001 records, and text filters as case-insensitive substring matches without stemming (#29).
- **`cpsc-recalls-guide` skill** 1.0 → 1.1: the lettered-number and last-published-date gates match the new behavior.

## Fixed

- **`cpsc_get_recall`** returns only the record whose number equals the request. The bare base of a lettered 1998–2001 family such as `01160` now fails `not_found` with a hint naming `01160a`, `01160b`, and `01160c`, instead of returning one of them (#28).
- **Upstream calls** share one 50 s deadline across every attempt, backoff, and the reordered provider-failure retry, so a stalled CPSC request ends as retryable `upstream_error` before an MCP client's default 60 s timeout (#30).
- **`content[]` web addresses in CPSC prose** that hold characters Markdown would consume (`*`, `_`, `&amp;`) or precede an escaped `<` render as a link over the address GFM autolinks, so every character shows under CommonMark and GFM. `structuredContent` is unchanged (#26).

## Dependencies

- Dev dependencies added: `micromark` ^4.0.3, `micromark-extension-gfm` ^3.0.0 (GFM rendering tests).
