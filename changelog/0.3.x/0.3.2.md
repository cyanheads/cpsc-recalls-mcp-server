# 0.3.2 — 2026-11-21

## Added

- **`cpsc_search_recalls`** filters by CPSC's classified `remedy_option` with exact category matching before pagination. ([#35](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/35))
- **`cpsc_search_recalls`** searches incident narratives via `injury_search` and returns `injuries` in each row. The source text can contain both reports and denials. ([#37](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/37))
- **`cpsc_get_recall`** accepts printed recall numbers such as `25-036`, surrounding whitespace, and uppercase letter suffixes. Set `CPSC_NORMALIZE_RECALL_NUMBERS=false` to require canonical strings. ([#38](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/38))

## Changed

- **Recall pagination** uses row counts, up to 500 per page for search and 1,000 for recent recalls. Set `CPSC_CLAMP_LIMITS=false` to reject requests above those caps. ([#33](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/33))

## Fixed

- **`cpsc_search_recalls`** finds full or trailing UPC digits in structured UPCs and descriptions. Open the full recall to confirm candidates found in descriptions. ([#36](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/36))
- **`cpsc_get_recall`** directs readers to product names, image captions, and the official recall page when CPSC omits the description. ([#34](https://github.com/cyanheads/cpsc-recalls-mcp-server/issues/34))
