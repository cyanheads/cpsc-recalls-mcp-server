# 0.1.8 — 2026-09-19

## Added

- **`cpsc_search_recalls` accepts `hazard` as an alias for `hazard_search`.** `Hazard` is the upstream CPSC query parameter a caller working from the saferproducts.gov docs reaches for; the alias is not advertised in `inputSchema`.

## Changed

- **`engines.bun` rises from `>=1.3.0` to `>=1.4.0`.** A consumer running Bun 1.3.x can no longer run the server.
- **`createApp()` declares `sessionMode: 'stateless'`** in `src/index.ts` — no tool here gates on `ctx.requestInput`, so no caller needs a session to answer a mid-handler prompt. `MCP_SESSION_MODE` still overrides the declared posture whenever it carries a meaningful value.
- **`tools/list`'s advertised `outputSchema` changes on two error-contract details; `inputSchema` is byte-identical.** Nullable string fields now render as `type: ["string", "null"]` instead of `anyOf: [{type:"string"},{type:"null"}]` — a semantically-equal re-rendering from the `zod` bump below. Each error-contract `reason` description now ends its `when` sentence with a period, so declared reasons no longer run into each other (mcp-ts-core 0.13.5, [#389](https://github.com/cyanheads/mcp-ts-core/issues/389)).
- **Tests updated for the `InvalidParams` rename** — an out-of-schema argument key now rejects as `InvalidParams` (`-32602`) rather than `ValidationError` (mcp-ts-core 0.13.2, [#416](https://github.com/cyanheads/mcp-ts-core/issues/416)).
- Framework skills moved from `skills/` to `framework-skills/` — Claude Code and Codex auto-load a plugin's root `skills/`, so keeping development skills there would hand them to every installing agent. Adds the `release-pr-review` skill and resyncs `scripts/`, `changelog/template.md`, and `devcheck.config.json`'s `lint` key.
- README condensed — an Overview section, a tighter per-tool capability reference, and the Bun 1.4.0 floor.
- `.claude-plugin/plugin.json` gains keywords and author contact; issue templates route reports between this repo and `mcp-ts-core` and add a security-advisory contact link.
- Adds `.github/workflows/codeql.yml` — the repo's only GitHub Actions workflow.
